## 🎨 Color System & Clean Design Rules

- **Base Colors**: Pure White (`#FFFFFF`) and Light Gray (`#F9FAFB`). No cream or muddy yellow-on-yellow backgrounds.
- **Dark Sections**: Rich Charcoal (`#111827`) for the top announcement bar, sticky header, on-site repair section, and footer.
- **Accent**: Warm Industrial Amber (`#F59E0B`) used **only** for buttons, active links, and key highlights.
- **Card Design**:
  - One badge per product card at most (`400A MIG`, `TORCH SPARES KIT`).
  - Exactly 3 key spec bullet points with amber dots.
  - Exactly ONE button per card (`Get Quote`), opening an instant quote modal with WhatsApp submission.
  - Equal height cards via CSS grid stretch.
- **Floating WhatsApp**: Clean 48px round green circle icon at the bottom-right corner without intrusive text labels.

## 📱 Mobile-First Responsive Breakpoints

- **Mobile (< 640px)**: 1 column, full-screen slide-in navigation with close button, non-obtrusive floating WhatsApp button.
- **Tablet (640px – 1023px)**: 2 columns for product and category grids.
- **Desktop (1024px+)**: 3 columns for products, 4 columns for categories, 2-column hero with 55%/45% split.
- **Large Desktop (1280px+)**: Max-width 1200px container with generous 5rem (80px) section spacing.
